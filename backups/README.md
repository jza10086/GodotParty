# Avalon presentation backup

`avalon_before_table_animations_20261027_233728.zip` preserves the complete identity-party package before the crown handoff, team portrait row, synchronized ballot flip, and five-cell quest-result animations added on 2026-10-27.

The archive contains the `godot_party_default_identity_party` folder, including its original UI, rules, assets, scenes and UID companions. To restore the earlier implementation, close the running game and copy this folder from the archive over `games/minigame/godot_party_default_identity_party`, replacing matching files. The newly added `avalon_table_effects.gd` is unused by the restored UI and may remain in place. Other project files and local settings are outside this backup.

The ZIP entry list was checked for the original Avalon UI script; no file hashes were calculated. This directory is excluded from Godot imports by `.gdignore`.
