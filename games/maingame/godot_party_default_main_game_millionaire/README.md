# GodotPartyDefaultMainGameMillionaire

独立城市冒险棋盘原型，沿用 Godot 4.7 Forward+ 与原版协议画质；没有正式游戏包 manifest，F5 仍进入框架。

## 山海环游完整地图

打开 `maps/mountain_bay.tscn` 按 F6 查看。`map_editor.tscn` 现在默认加载这张地图；旧 `map_preview.tscn` 城市地图仍可单独打开。

设计参考：[《大富翁11》官方传统地图介绍](https://rmxi.softstargames.com.tw/)，借鉴道路连接地产与功能格、岔路提供取舍的组织方式。布局和场景为本项目制作，没有下载或使用该游戏素材。

43×35 米矩形地图完整覆盖 1505 个地面格；303 个作者 Cell 定义地面、道路及建筑占地。主环线顺时针行进，西南侧红旗为唯一出发点。212 个玩法节点包括 176 处地产、14 个事件格、11 个钻石格、4 家商店、3 个分叉、3 个汇流和 1 个起点。

| 路段选择 | 短线 | 长线 |
| --- | --- | --- |
| 松风林地 | 9 步，1 家商店 | 29 步，3 个钻石、2 个事件 |
| 银顶雪岭／湖畔 | 13 步，1 家商店 | 29 步，3 个钻石、2 个事件 |
| 赤岩峡谷／海湾 | 9 步，1 家商店、1 个钻石、1 个事件 | 25 步，4 个钻石、3 个事件 |

步数只计算消耗行动力的格子，分叉和汇流免费。短线适合补给和快速通行，长线以更多经过型钻石格和停留型事件格换取额外路程；三条支路均汇回主环，没有永久困住玩家的支路。钻石交易和事件奖励的实际经济收益仍由后续主游戏规则决定，尚未进行整局平衡验收。

场景包含钟声小镇、松风林地、银顶雪岭、澄镜湖、赤岩峡谷、晴沙海湾和田园绿洲。地形通过铺地、雪峰、树群、砂岩、河流、桥栏、果园、码头和灯塔区分；可行走道路保持统一高度与现有移动规则，未引入坡度或地形移动惩罚。桥面不放地产。

`Cells` 中的数据可用现有运行时地图编辑器修改；`Landmarks` 中的地形地标、建筑、桥栏和地区文字为原生节点，可在 Godot 编辑器直接调整。运行时地图编辑器保存时保留这些场景地标，暂不自动随道路移动。根节点 Inspector 可设置标题、说明、全景距离和观察角度。新增几何体为程序制作，建筑与字体复用已有授权素材。

本轮验证：Godot 4.7.2 下 `tmp/test/mountain_bay/map_test.gd` 通过整图覆盖、占地、单行连通、回环可达、分叉步数、功能格分布及预览引用检查；1920×1080 透视与俯视画面已检查，地图编辑器默认加载成功。截图为 `tmp/test/mountain_bay/overview.png`、`route_overview.png`；这些本地文件不参与发布。尚未接入完整联机对局或老虎机事件。

## 独立 2D 老虎机场景

打开 `slot_machine/slot_machine.tscn`，按 F6 独立试玩。点击“转动一次”，三个转轴依次减速停下；只判定中间横线。五种图案等概率，三连倍率为樱桃 5、柠檬 8、铃铛 12、钻石 20、幸运七 50；任意一对为 1，其他为 0。右上角可查看玩法。倍率仅用于演示，不扣款、不结算金币，尚未接入地图事件或联机。

场景使用原生 Control、容器和可编辑 StyleBox；转轴图案由 `slot_reel.gd` 绘制，复用协议字体，无新增外部素材。Inspector 可调整 `spin_duration`、`stop_interval` 和 `allow_random_spins`。

后续事件可在场景进入树后调用 `play_result(PackedInt32Array([a, b, c]))` 播放指定结果，图案 ID 0–4 分别为樱桃、柠檬、铃铛、钻石、幸运七；将 `allow_random_spins` 预设为 false 可禁用本地随机按钮。`start_spin(seed)` 用于可复现的独立随机试玩。转动期间再次调用返回 false；完成时发出 `spin_finished(symbols, multiplier)`，由未来的事件控制器决定是否及如何结算。

针对性自动检查：`godot --headless --path F:/GodotProjects/GodotParty --script res://tmp/test/millionaire_slot/slot_machine_test.gd --log-file F:/GodotProjects/GodotParty/tmp/test/millionaire_slot/runtime.log`。覆盖组合规则、重复请求拒绝、指定结果快照、停轮一致性、完成信号次数、种子复现和外部结果模式。测试脚本与截图位于本地忽略目录 `tmp/test/millionaire_slot/`，不是发布依赖。

## 查看与编辑

打开 map_editor.tscn，按 F6 运行地图编辑器。默认载入 maps/mountain_bay.tscn；右侧面板操作笔刷，地图修改只发生在运行进程。所有棋盘脚本均不使用 @tool，旧 Godot 编辑器插件已删除。每格 1m×1m，地图场景 Cells 下的作者 Cell 是唯一来源。

点击“保存地图”或 Ctrl+S 才写回 .tscn，支持另存为、打开和清空。允许保存尚未连通的草稿。临时写入与旧版本备份位于 tmp/map_writes/ 和 tmp/map_backups/；保存失败保留内存数据。正常关闭窗口或打开其他地图前有未保存提示，Godot 强制停止进程不保证触发提示。当前只用于源码工程内编辑，不是导出游戏中的玩家地图分享工具。

只查看地图时仍可打开 map_preview.tscn 并按 F6；Godot 编辑视图不再自动构建模型。先保存 Godot 中尚未写盘的场景修改，再从运行时编辑器打开该地图。

- 放置：选择起点、地产、分叉/汇流、事件、商店、钻石、装饰，左键放置，长按拖动连续绘制；快速移动会补齐经过的网格，同一笔不重复处理。半透明模型和占地跟随鼠标，冲突显示红色。可直接覆盖没有装饰的纯地面格，不能覆盖建筑或玩法格。
- 删除：按住右键拖动，临时使用删除笔刷，松开后恢复原笔刷；也可选择删除笔刷后用左键操作。删除整个对象；双格的道路和建筑一起删除。需要地面时再放置空装饰格。
- 复制：点击已有对象任一占地，吸取全部参数并自动切换放置，副本生成新 ID。修改面板后也可点击“应用到当前选中地格”编辑原对象。
- 旋转：3D 视图内 R 顺时针、Shift+R 逆时针，每次 90°。旋转的是笔刷参数；修改原对象需要应用。Ctrl+Z / Ctrl+Shift+Z 撤销重做，整次拖动为一笔。
- 视角：运行时编辑器采用 Blender 风格的中键旋转、Shift+中键平移、滚轮缩放；面板有重置视角按钮。R 用于旋转笔刷，不修改 Godot 全局快捷键。独立 map_preview 的 R 仍为重置视角。
- 参数：道路统一采用一层 0.12 米厚地基，顶面为 0。建筑侧和装饰地格从 −0.12 米底面向上叠加一至三层，每层独立设置厚度、颜色、外边距和内边距。外边距从完整地格边缘向内收缩；内边距为从外轮廓向内量取的边框宽度，0 表示实心，达到半宽时也为实心。边框中央开口，不加顶面盖板，可露出下层颜色；例如上层厚度 0.03、外边距 0、内边距 0.05，可得到 5 厘米宽边框；默认一层与道路等高。建筑和表面随总高度抬升。未使用层级隐藏，非路口隐藏路口规则；双出口布局仅在十字双出入口显示。旧公共层厚、退台与建筑侧抬高参数不再读取。建筑/装饰场景及尺寸仍可配置。只接受 Node3D 根场景；原地图装饰片段保留原有变换。
- 地产/商店为双格，建筑侧方向由面板控制；建筑格不参与行动。装饰可设置 1–32 格的宽（局部 X）和长（局部 Z），如 2×2、2×3；其他类型为单格。多格装饰以鼠标地格为锚点，R 旋转整组占地，任一格都可整组高亮、吸取、删除和撤销。地基及边框按整组矩形生成。所有表现为 Cell 内可重建节点，不要直接编辑 Visual 子树。

### 路线推导

普通路段根据相邻玩法格自动选择直路/弯路，三向连接必须使用路口，自动使用带斑马线的 T 形模型。装饰与建筑侧不参与道路邻接。十字路口使用 road-crossroad.glb，支持三进一出、一进三出、两进两出。

起点方向的 +X（局部右侧）是默认出发连接，旋转后随方向改变。单入口路口指定入口，单出口路口指定出口；两进两出指定第一出口，第二出口可选顺时针相邻或相对方向，其余端口为入口。T 型要求三条邻路，十字型要求四条邻路；没有路口约束的简单环路在起点接入处优先右转。路口方向冲突产生双向时明确报错，不自动猜测修复。

“检查路线 / 生成运行数据”检查重叠、重复 ID、起点、断路、路口端口、双向和可达性。无效草稿允许保存，但不会生成可运行定义，F6 不启动地图逻辑。合法图在运行时从 Cell 重新生成，不读取过期快照。

实现：editor/map_editor.gd 为运行时面板；本目录 editor/board_cell.gd、board_authoring.gd、board_routes.gd 为地格表现与纯路线推导。框架 core 不依赖此工具。

## 矩形城市冒险布局

不规则单行环线串联旧城、林地和湖畔；两条可选支路分别穿过林地区域、中央湖区。只有两处分岔需要选择，两处汇合自动继续。底盘为 35×29m 完整矩形，保留不规则道路与内部支路，外围填充商业区、工业角、绿地、公园设施与滨水留白。

- 地基按街区连续铺设：道路与建筑周边采用统一铺地，填平住宅间的零碎草地；保留 123 格成片公园绿地和 46 格水面，绿地使用统一色调。
- 872 个作者 Cell（含 143 个双格）覆盖 1015 个地面格，157 个玩法节点：起点 1、地产 140、事件 6、路口 4、商店 3、钻石 3。
- 起点以小红旗标识，不使用文字，是 (-15,4) 的单独可行走地块，直接进入相邻道路，不设置侧面装饰格、入口牌或额外连接格。普通移动不能返回。
- 所有普通道路单行互通，没有死路。分叉与汇流路口每个端口各显示一个小箭头，黄色向外表示出口、青色向内表示入口，尚未连路的草稿也立即显示；起点额外绘制一个指向入路方向的小箭头。直路不画箭头。四处 T 路口使用带斑马线的 road-intersection-path.glb。箭头、问号、钻石和红旗均放在对应 Cells/Cell*/Markers 下，以地格局部坐标定位，随地格一起移动。
- 140 处地产使用 building-type-a.glb，尽量沿路同侧布置。靠路侧 PropertyBand 标识对应道路地产和归属，初始为无主灰色；不在路面重复画地产色条。
- 三个商店使用 building-type-b.glb 与橙色招牌，shop_cell 记录侧面展示节点；商店没有地产归属。
- 钻石仅使用路面青色菱形，事件用问号；没有对应的侧面建筑。
- SeamGrid 是单独一张 37×31m 诊断网格，金色边框标出 35×29m 底盘；不代表实际地图边界。

## 规则与表现边界

运行时生成的 board_definition.gd 资源的 tiles 保存 id、x/z、kind、next、property_cell，以及商店可选 shop_cell。地产格与展示位置一一对应。

`step(from_id, to_id, remaining)` 是纯裁定，返回 ok/tile/remaining/choose_exit/interaction/settlement/finished：

- 起点、路口零消耗；其他格进入即消耗一点。行动力耗尽后不额外穿过免费路口。
- 地产、事件只在最终停留时返回 settlement。
- 商店、钻石经过即返回可选 interaction，包括最后一点行动力；取消或完成交易后继续剩余行动，不额外扣点。
- 非法方向和逆行被拒绝。特殊返回起点由后续业务直接安置，不添加普通返回路线。

`board_markers.gd` 在编辑器和运行时读取同一份数据生成标记，不保存第二套路向。`set_property_color(tile_id, color)` 只改变对应 PropertyBand 的局部材质，不决定归属或修改其他地产。

尚未接入骰子、棋子移动、交易界面、购买/升级/收租、钻石经济、事件执行、联机或正式框架生命周期。金币收入与最终排名仍由后续大游戏规则实现。

## 装饰与交互对象区分

- 140 处可购地产仍为绿色屋顶住宅，靠路边 PropertyBand 表达归属；3 个商店为另一种住宅模型及橙色招牌。
- 41 栋纯装饰建筑使用现有商业楼、工业楼和水塔，与地产住宅不同，节点名 SceneryBuilding，没有 PropertyBand，不进入运行时路线的交互列表。
- 公园配置树木、21 组长椅和 2 处小喷泉；46 个水面地块形成湖区与工业角滨水区。
- 装饰模型居中缩放，水平尺寸不超过 0.78m，最高 1.25m；保留道路和特殊地格空间，起点没有附属装饰。
- 装饰只使用已安装的 Kenney 素材和基础几何，没有新增下载资源。矩形外围浅色步道为景观，不是可行走地格。

此次扩建保持地块 1m×1m，重排道路坐标并加长路段；主要相邻平行道路中心距至少约 4m（连接和转弯处除外）。两处关键分岔不变，减少单位面积装饰密度，路间留出较宽绿地。默认远裁剪 150m，以覆盖放大的全景。

tests/millionaire_runtime_editor_test.gd 在独立进程检查空位置单格预览、长按绘制/删除、整笔撤销重做、双格删除、旋转及保存/覆盖/回读。实际运行窗口已渲染检查，鼠标手感仍需人工验收。删除/复制在空位置只显示一格，已有双格对象仍显示完整占地。

装饰地标采用米制原尺寸，模型根原点在整组水平几何中心，不按单格自动缩放；尺寸倍率默认 1。模型底面仍对齐主模型所在层。作者需保证模型不超出声明占地；已有装饰的显示尺寸可能随取消单格归一化改变。

## 批量调整
Shift+左键加选同类地格，Ctrl+左键减选；点击双地格任一侧均作用于整个对象。首次选择读取参数，修改面板后点击批量调整。全选按钮选择面板当前类型，暂不支持装饰。批量替换保留 ID、位置与朝向，可整批撤销。有选择时右键地图仅清空选择；无选择时仍为删除笔刷。金色高亮为批量选择，数量按对象计算。
