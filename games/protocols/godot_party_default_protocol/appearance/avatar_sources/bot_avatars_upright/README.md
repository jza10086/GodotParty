## 生成风格与提示词要点

- 日系 Q 版、大头半身正面头像；正面直立、没有头部侧倾或镜头倾斜。
- 脸和下巴的中心轴竖直，两只竖向圆角矩形实色眼睛等高，粉色腮红左右平衡。
- 不绘制嘴、鼻、眉、睫毛、瞳孔或眼白。
- 扁平赛璐璐块面发丝、低饱和配色、奶油白肤色、深炭灰背景。
- 保留上一组各角色的发型、衣着与饰品特征；图片为正方形 PNG。

生成方式：内置图像生成工具；第一组对应头像作为角色与画风参考，重新绘制姿态。
