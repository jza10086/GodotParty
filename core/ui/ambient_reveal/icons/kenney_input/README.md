# Kenney Input Prompts

Author: Kenney
Package version: 1.5A
License: CC0 1.0, see License.txt.
Imported on 2026-11-09.

The keyboard_mouse directory contains all 257 original Keyboard & Mouse SVGs.
The xbox directory contains all 99 original Xbox Series SVGs.
These are unchanged vectors from the official download. No bitmap duplicates are included.

Shared input prompts use these glyphs through components/navigation/action_prompt.tscn.
Use vertical_hints.tscn for a bottom-left or bottom-right list.
