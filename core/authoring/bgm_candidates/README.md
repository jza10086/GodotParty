# 小游戏 BGM 候选素材库

完整选曲与游戏对应关系见 [BGM 清单](../../../doc/bgm_candidates.md)。

- `audio/`：29 个已下载音频文件／版本。
- `sources/`：逐曲作者、许可、来源与原始下载地址。
- `catalog.json`：音频时长、文件大小、作者、风格和循环说明。
- `archives/`：Exploration Theme 原始 ZIP；其中 OGG 已提取到 audio/。
- `LICENSE-CC0.txt`：所选 CC0 1.0 Universal 许可全文。

本库所有条目采用原作者在曲目来源页提供的 CC0；不属于本项目原创音乐。可免费商用、修改和再分发，无须强制署名，仍建议保留来源。尚未接入运行时；`.gdignore` 阻止候选库自动导入。选定音乐后将音频和来源／许可旁档复制至对应小游戏包。
