# 小游戏场景与 HUD 检查清单

2026-11-04。按 `games/minigame/*/manifest.json` 的入口及其直接加载的玩法场景、视图脚本静态检查，共 23 包。两项标记为未开放的包另看其独立原型。下列路径相对各自的包目录。下表按包记录迁移状态。未标记完成的条目仍待实施。
