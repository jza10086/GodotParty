# 开发原则

项目规则以根目录 AGENTS.md 为准；内容作者先读 [文档入口](README.md)。

- 完整 core 工程是唯一开发环境，开发参数只选择正式大厅的输入。
- 一个大游戏控制器和一个前台小游戏；中游戏只是 tag，连续模式是大游戏。
- core 管理会话、加载、提交和公共界面；经济、回合和胜负由大游戏及协议解释。
- 每个包只有 manifest.json；安装新源码后自动发现，不手改核心目录资源。
- 小游戏是普通场景的三个钩子。大游戏控制器持续存在，视图可释放，长期状态必须可序列化。
- 房主协调和最终发布不等于强制房主计算每个玩法。PartyNet 与原生联网可共存。
- 结果归约是纯函数；状态与已处理轮次在一个双槽记录内提交，保存后才能公布奖励。
- 玩家形象字段归协议，core 只验证公开资源引用和协议认可的数据。
- 同进程内容拥有普通 Godot 能力。本轮没有沙箱、源码审核或系统函数黑名单。
- 验证按修改边界进行；自动、人工观感、八人、外网和 Steam 结果分开记录。

工程仅保留 API 4 运行器；旧 GPActivity 契约、固定形象槽位和文本协议加载器已删除。
