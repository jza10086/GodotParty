# 连通性测试

主界面提供两个独立入口：「监听测试」等待其他设备访问，「连接测试」主动向目标 IP 或域名发起探测。两者均独立于游戏房间，支持 UDP/TCP、手动端口及 IPv4/IPv6。默认端口 7777，监听前请避免与游戏房间或其他程序冲突。关闭窗口、切换测试窗口或其他弹窗、退出应用，都会停止当前测试并释放套接字。

UDP 模式下，先选择「UDP 监听 / 回包 IP」，再开始监听。套接字只绑定这个本机地址，回复使用同一地址和监听端口；其他设备也必须向这个地址发送请求。监听期间地址选择与刷新会锁定，切换 IP 需先停止。IPv4/IPv6 选项用于筛选候选地址，一次 UDP 监听只使用一个地址。

开始监听后复制客户端链接，如 `udp://192.168.1.10:7777` 或 `tcp://[2001:db8::1]:7777`。“分享域名”留空时，UDP 链接使用实际绑定的地址；填写有效域名时，复制客户端 / 网页链接会使用该域名，例如 `udp://game.example.com:7777`、`http://game.example.com:7777/`。分享域名不改变监听绑定，也不自动配置 DNS；需让域名及端口指向该监听服务。TCP 仍按地址族监听所有地址，下拉框只用于选择分享地址。IPv4 私网地址仅适用于对应局域网或有路由的网络；本机绑定不证明公网可达，NAT 仍可能转换外部可见地址。工具不创建端口映射、不中继、不自动修改防火墙。

安卓客户端源码位于 `tools/connectivity_client/project/`，UDP/TCP 均支持。正式游戏连接仍是 ENet/UDP；测试成功只证明此次探测的双向通信，不证明游戏会话握手通过。

## PC 连接测试

先让目标 PC 打开「监听测试」并开始监听，再在本机打开「连接测试」，填写目标 IP 或域名、端口和相同协议，或粘贴监听端复制的链接。粘贴只填入字段，点击「开始测试」才发送探测。运行中锁定输入，停止后可修改；可复制含目标地址、探测次数、成功/超时/错误/取消次数、最近和平均往返耗时的结果。

连接测试与安卓客户端行为相同，目标需支持 GPTEST/1 回复。每次最多等待 3 秒，通常每秒探测一次；TCP 每次新建连接，耗时包含建连时间。PC 使用 `core/network/connectivity/probe_client.gd`，安卓独立工程保留同一实现的副本；回归检查会核对两份代码（仅允许工程资源路径不同）。不保存地址或测试结果。

域名支持 ASCII / Punycode（含 localhost）；地址框填写纯域名，或用“粘贴地址 / 链接”导入 `域名:端口`、`udp://域名:端口`、`tcp://域名:端口`、`http://域名:端口/`。DNS 异步解析最多 3 秒，每次开始测试解析一次，使用系统返回的首个 IPv4 / IPv6 地址；结果必须通过现有单播 IP 校验。报告显示域名及实际目标 IP，DNS 时间不计入探测 RTT。解析失败、超时或结果不受支持时停止，用户可修改后重新开始；不会轮换地址重试。停止、关闭窗口和进入后台会释放待处理查询。

## 公共探测协议 GPTEST/1

UTF-8 / ASCII 文本，无 Godot Variant 序列化。请求及对应回复示例：

```text
GPTEST/1 PING 42 a83f19000000000000000000
GPTEST/1 PONG 42 a83f19000000000000000000
```

- 序号为十进制正整数，范围 1–2147483647；随机标识为 24 个小写十六进制字符。客户端每次生成新的 12 字节随机值。
- UDP：一个数据报一条消息，不含换行。只接受最多 96 字节的合法 PING；回复与请求等长。客户端使用连接式 UDP 套接字过滤其他来源，再比对完整 PONG。
- TCP：一条消息以 LF 结束，也接受 CRLF。服务端处理一个请求、完整提交一个回复后关闭连接。客户端每次探测新建 TCP 连接，支持分段发送/接收，连接成功本身不计成功。
- 客户端单次总超时 3 秒，包含 TCP 建连；通常每秒一次，超时后再进行下一次。只保留一个待回复请求。停止和进入后台关闭连接，未完成请求计为取消。
- 统计中的超时是探测超时，不能当作精确的网络丢包率。服务端「回复提交」只表示交给本机网络栈，不表示远端已经收到。
- 服务端限制每帧最多处理 32 个 UDP 数据报、每秒最多回复 64 个有效 UDP 请求；TCP 最多同时 8 个客户端、每秒接纳 64 个连接，每个连接最多 4096 字节输入、5 秒生命周期。无效或超额输入被忽略/断开，不解释为游戏消息。

## 浏览器 / 其他工具

TCP 监听时复制「网页链接」，在其他设备浏览器中打开 `http://地址:端口/`（IPv6 使用方括号）。服务端返回自包含页面，每秒访问同源 `/ping?nonce=...` 并检查 JSON 回复中的 nonce。网页使用 3 秒超时和禁止缓存；无需额外网站、账号或服务器。HTTP 仅用于不含敏感数据的网络探测。

也可使用 `curl 'http://192.168.1.10:7777/ping?nonce=123abc'`，预期得到 `{"nonce":"123abc"}`。浏览器不能直接发原始 UDP，请使用客户端或其他 UDP 工具，并按上述格式收发。

同一 TCP 端口按请求首行区分 GPTEST 和 HTTP。浏览器成功不代表 UDP 可达；必须分别测试两种协议和需要使用的地址族。外部网络、运营商、路由器和防火墙的最终连通性需要双方实际设备验证。
