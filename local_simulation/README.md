# 阿瓦隆离线模拟场景

在 Godot 编辑器打开 `res://local_simulation/avalon_simulator.tscn`，按 **F6（运行当前场景）**。无需创建房间、连接其他客户端或启动主菜单。

这是交互式本地模拟工具，不属于自动化测试；相关脚本与场景统一保存在 `local_simulation/`。

## 操作

- **F1**：收起/展开右侧控制台，完整查看牌桌。
- **F2**：重建并重播当前预设，包括皇冠交接、翻票和落格的前后画面。
- 人数选择支持 **5～8 人**；玩家下拉框可切换每个座位和观战者。控制台标出完整身份，正式牌桌仍使用当前玩家的过滤快照。
- 直接点击正式牌桌完成选人、投票、刺杀、查看百科和退出确认。其他玩家可通过控制台逐个代操作，或勾选自动代操作。
- 默认保留结果页供观察；勾选“结果满 3 秒自动推进”后使用原有三秒规则。也可以点击“推进结果”。
- 支持 **0.25× / 0.5× / 1× / 2×**、暂停、**步进 1/30 秒**和减少动态效果。暂停时牌桌交互也暂停，控制台仍可使用。离开场景后恢复原来的引擎速度。
- “重复快照 ×10”用于检查动画和字幕是否被重复状态打断；“模拟过期请求”使用真实规则拒绝旧阶段请求。
- 自动代操作只处理其他玩家，当前玩家仍需你手动选择。观战者视角下可以自动处理全部玩家。选择“偏向反对 / 破坏”时，好人仍只能提交成功。

## 29 个预设的覆盖范围

| 范围 | 场景 |
| --- | --- |
| 开场、组队 | 序言、队长选人、选中/取消与头像入列、皇冠交接 |
| 公开投票 | 无人提交、部分完成、最后一票、多数通过、多数否决、平票否决 |
| 秘密任务 | 好人、坏人、非队员等待、最后一张牌、成功与失败落格 |
| 多轮任务 | 第四轮一张失败仍成功、两张失败判失败、第五轮决胜、五格完成 |
| 刺杀与终局 | 刺客操作、其他身份等待、刺杀落空、刺中梅林、三次失败、连续五次否决 |
| 其他视角与交互 | 观战、取消、八人长名字；各场景均可切换角色、百科、重复状态和过期请求 |

平票预设将奇数人数调整为下一档偶数人数；第四轮双失败票预设至少使用七人；长名字预设使用八人。这些调整在人数选择框中可见。

预设通过 `identity_match.gd` 的真实行动接口推进，不直接篡改规则状态。转场前的快照已按每位玩家过滤，演出仍由正式 `avalon.gd` 和 `avalon_table_effects.gd` 绘制。只在此本地模拟场景中提供代操作，不注册正式游戏机器人或修改大厅入口。

这是当前阿瓦隆规则与表现的离线查看工具；真实网络延迟、掉线传输、房间加载、设备输入和外网连通性需要另外验收。取消预设调用真实模型的取消接口，控制台显示取消原因；保留原有牌桌的当前阶段显示。
